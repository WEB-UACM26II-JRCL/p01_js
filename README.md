## Descripcion

Juego en el que el navegador genera un numero secreto entre 1 y 100. El usuario
escribe intentos y recibe pistas hasta adivinarlo. La pagina muestra cuantos
intentos lleva y permite comenzar un juego nuevo.

## Objetivo

Aplicar variables, estructuras de control, funciones, `console.log()`,
`alert()`, `prompt()`, `Math`, `onclick` y `document.getElementById()`
para desarrollar una pagina web interactiva.

## Archivos

- `index.html`: estructura de la interfaz (proporcionado).
- `style.css`: presentacion de la interfaz (proporcionado).
- `app.js`: comportamiento programado por el estudiante.
- `README.md`: descripcion y evidencia del trabajo.

## Como ejecutar

1. Descargar o clonar el repositorio.
2. Abrir `index.html` en un navegador.
3. Escribir un numero entre 1 y 100 y presionar **Comprobar**.
4. Leer la pista y repetir hasta acertar.
5. Presionar **Nuevo juego** para comenzar otra partida.

## Temas utilizados

Variables, condiciones, funciones, consola, ventanas de aviso,
entrada de datos, generacion de numeros aleatorios y manipulacion del HTML.

## Pruebas realizadas

- [ ] El boton Comprobar muestra pistas correctas.
- [ ] El contador aumenta al ingresar un intento valido.
- [ ] Se detecta el numero correcto.
- [ ] El boton Nuevo juego reinicia el contador y el mensaje.
- [ ] Los valores vacios o fuera de rango no se consideran intentos.
